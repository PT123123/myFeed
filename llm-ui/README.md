# 阅流手机端：LLM Feed 模块

手机主界面有独立的「订阅阅读」和「LLM Feed」tab。此目录包含随 APK 离线打包的 LLM Feed 界面源码，不依赖电脑上的网页开发服务器。

界面基于 `personal-ai-feed` 的 `da72aa7` 版本，保留 Feed、发现、收藏、生成、设置、提示词、人格、来源和用量页面，以及 IndexedDB 缓存、同步游标和操作队列。手机端维护此副本和 Android 宿主适配；电脑端继续维护服务端 API。同步桌面界面改动时需保留 `src/mobile/`、手机连接设置和原生文件导入导出适配。

`pnpm install --frozen-lockfile` 后运行 `pnpm build` / `pnpm test`。Android 的 Gradle 构建会自动安装锁定依赖、构建此目录并把产物加入 APK；无需邻接的电脑端仓库。`dist/`、`node_modules/` 和本机配置均不提交。

首次运行不填充演示帖子或个人兴趣。用户在 LLM Feed 的设置中保存电脑地址；后台同步完整 Feed、评论、主题、阅读状态和待上传操作。旧原生 AI 缓存会在本机导入一次。旧独立 Android 应用的数据需要先导出 JSON，再在新应用的备份入口导入。

Android 通过仅允许本地应用来源调用的消息接口访问已保存的电脑服务；仅转发同一服务的 `/api/v1/*` 和 `/health` 请求。外部网站在系统浏览器打开，不获得此接口。文件导入与导出通过系统文件选择器完成。模型密钥由服务端保管，界面和 APK 不包含密钥、个人画像或实际电脑地址。

离线时保留内容、收藏、评论草稿和同步队列；生成任务、服务器设置修改及来源采集需要电脑服务在线。电脑开启 `just server-lan` 后手机才能从同一可信局域网连接。服务端若开启鉴权，需完成受信任的连接授权；当前版本不自动关闭服务端鉴权。
